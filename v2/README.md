# Economy Pro v2 — Telegram Mini App + Cloudflare Worker + D1

**Статус:** независимая версия в папке v2/. Старый Netlify-проект, его база и работающий главный сайт не изменены.

## Возможности

- Telegram-бот: /start и /menu дают кнопку «Открыть тест». Владелец дополнительно получает кнопку «⚙️ Админ-панель» (команда /admin).
- Mini App: мобильный интерфейс, плавные переходы, предметы и тесты.
- Админка внутри Mini App доступна только после серверной проверки подписанного Telegram ID.
- Выдача Premium на N дней, отмена Premium, бан/разбан по Telegram ID.
- Создание/удаление предметов. Импорт вопросов по темам.
- Пользователи: Telegram ID, имя, username, последняя активность, Premium и блокировка.
- Активность обновляется при /start и открытии Mini App, далее примерно раз в 25 секунд при активном приложении. «В сети» означает активность Mini App за 45 секунд, а не общий онлайн в Telegram.
- Список пользователей обновляется каждые ~4 секунды, а клиентская проверка Premium/бана — каждые ~8 секунд. В базу операция записывается сразу после подтверждения, но задержка сети не исключена.
- Сервер проверяет Telegram initData HMAC-SHA256 и срок (24 часа). Все админские API требуют OWNER_TG_ID; журнал действий записывается отдельно.
- Импорт TXT, DOC, DOCX, PDF или вставленного текста. Извлечение — в браузере владельца, серверу отправляются только вопросы.

## Шаблон

    Тема: География

    1. Столица Узбекистана?
    a) Москва
    b) Ташкент#
    c) Бишкек
    d) Пекин

    Тема: Экономика

    2. Что такое ВВП?
    a) Валовой внутренний продукт#
    b) Валовой внешний продукт
    c) Внутренние валютные платежи
    d) Внешний валовой платёж

Правильный вариант отмечается # в конце. Варианты должны идти a, b, c, d; кириллические а, б, в, г тоже распознаются. Несколько тем в одном файле разделяются заголовками «Тема: ...».

Ограничения импорта: сканированные PDF без текстового слоя требуют OCR. Шифрованный или слишком старый DOC может не распознаться — пересохраните в DOCX. Файл до 15 МБ, PDF до 150 страниц, отправка партиями по 100 вопросов. Повторный импорт может создавать дубликаты. Библиотеки обработки документов загружаются из внешних CDN при импорте; перед масштабным запуском стоит разместить зафиксированные версии локально.

## Установка

Нужны Node.js и бесплатный аккаунт Cloudflare. Откройте терминал в папке v2 и выполните:

    npm install
    npx wrangler login
    npx wrangler d1 create new-quiz-v2

Скопируйте выданный database_id в v2/wrangler.toml вместо REPLACE_WITH_D1_DATABASE_ID.

Создайте таблицы:

    npx wrangler d1 execute new-quiz-v2 --remote --file=./schema.sql

Установите секреты в интерактивном режиме, не публикуя их в репозитории:

    npx wrangler secret put BOT_TOKEN
    npx wrangler secret put OWNER_TG_ID
    npx wrangler secret put WEBHOOK_SECRET
    npx wrangler secret put PUBLIC_URL

BOT_TOKEN — токен бота из BotFather. OWNER_TG_ID — ваш числовой Telegram ID (не username). WEBHOOK_SECRET — случайные 16–64 символа (A-Z, a-z, 0-9, _ и -). PUBLIC_URL — фактический адрес HTTPS Worker без / в конце.

Развёртывание:

    npx wrangler deploy

После получения адреса Worker проверьте PUBLIC_URL и при необходимости установите секрет повторно.

## Подключение Telegram webhook (только при переходе на v2)

ВНИМАНИЕ: вызов setWebhook для существующего бота **заменит его предыдущий webhook**. Пока v2 не проверен, не переключайте рабочий бот.

Пример для Bash, где токен вводится без эха:

    read -rsp 'BOT_TOKEN: ' token; echo
    read -rsp 'WEBHOOK_SECRET: ' secret; echo
    curl -fsS "https://api.telegram.org/bot$token/setWebhook" \
      -d "url=https://YOUR_WORKER_DOMAIN/api/telegram-webhook" \
      -d "secret_token=$secret"

Замените YOUR_WORKER_DOMAIN на домен Worker. Для Windows используйте защищённый локальный терминал, не размещайте токен в коде. Затем напишите боту /start. Владелец увидит две кнопки, остальные — одну.

## Безопасность и данные

- Cloudflare D1 хранит users, subjects, questions, audit_log.
- Адрес /index.html#admin не является способом получить права: каждое действие /api/admin/ защищено проверкой Telegram подписи и OWNER_TG_ID на сервере.
- Webhook Telegram требует секретный заголовок X-Telegram-Bot-Api-Secret-Token.
- Бот не получает список всех пользователей Telegram. В базе появятся только те, кто взаимодействовал с новым приложением. Старые данные Netlify не мигрируют автоматически.
- Cloudflare Workers/D1 имеют бесплатные лимиты; при их превышении система может временно перестать принимать запросы. Настройте мониторинг и резервное копирование D1.
